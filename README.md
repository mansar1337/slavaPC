# Куманцов ПК .ru

Android-приложение в формате **APK** — витрина компьютеров с каталогом, корзиной и оформлением заказа.

> Оплата онлайн не проводится: заказ оформляется без списания средств. Платёжные сервисы
> не подключены, данные карты не запрашиваются ни на одном шаге.

## Готовый файл

```
dist/Kumanpc-ru-1.20.2.apk   (36 МБ, подписан)
```

Установка на телефон: скопировать APK → открыть файл → разрешить установку из неизвестных источников.
Требуется Android 8.0 (API 26) или новее.

## Структура проекта

```
Kumanpc-ru/
├── build.ps1                      сборка APK (aapt2 → javac → d8 → apksigner)
├── dist/                          готовый APK
└── app/src/main/
    ├── AndroidManifest.xml
    ├── java/ru/kumanpc/app/
    │   └── MainActivity.java      WebView-оболочка, без AndroidX и внешних зависимостей
    ├── res/                       иконка, тема, строки
    └── assets/
        ├── index.html
        ├── css/app.css              ← + liquid glass (SVG-преломление поверх)
        ├── js/data.js             ← каталог, цены, контакты, промокоды
        ├── js/app.js              логика, роутер, корзина, конфигуратор, реклама
        ├── img/                   фотографии товаров и услуг
        └── ad/                    видеореклама (mp4) + постеры в img/
```

Интерфейс — локальные ассеты, которые отдаются WebView через виртуальный адрес
`https://kumanpc.ru/`. Интернет приложению не нужен.

## Что можно менять

Всё редактируется в одном файле — `app/src/main/assets/js/data.js`:

* `SHOP` — имя, контакты (номер, Telegram, почта, адрес), цены доставки, гарантия, текст дисклеймера;
* `PRODUCTS` — товары: `name`, `price`, `old`, `art` (цвет SVG) или `img` (фото), `specs`, `feat`;
* `CATS` — категории;
* `CFG` — данные конфигуратора.

## Пересборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипту нужен JDK 17 и Android SDK build-tools 34 (по умолчанию берутся из
`%LOCALAPPDATA%\Temp\opencode\build\toolchain`). Путь можно передать параметром:

```powershell
.\build.ps1 -Toolchain "C:\путь\к\toolchain" -VersionName 1.0.1
```

Ключ подписи создаётся автоматически и лежит в
`%LOCALAPPDATA%\Temp\kumanpc-keystore\kumanpc.keystore` (пароль `kumanpc2024`).
Обновляйте APK тем же ключом, иначе придётся удалять старую версию перед установкой.

Особенность сборки: исходники копируются во временную ASCII-папку — `aapt2` не умеет
кириллицу в путях. Ассеты добавляются в архив через `jar`, потому что `aapt2 -A` на Windows
кладёт их с обратными слэшами, и `AssetManager` их не читает.

## Публикация на GitHub Pages

Сайт в папке `site/` — чистая статика (относительные пути, хэш-роутер `#/...`,
без бэкенда), поэтому выкладывается на Pages как есть.

В репозитории уже есть:

* `site/index.html` — сам сайт;
* `site/404.html` — копия главной для несуществующих URL;
* `site/.nojekyll` — отключение Jekyll;
* `.github/workflows/pages.yml` — автодеплой папки `site/` при пуше в `main`.

Шаги:

```bash
git init
git add .
git commit -m "Kumanpc-ru site + android app"
gh repo create Kumanpc-ru --public --source=. --push
# или вручную: создать репозиторий на github.com и
# git remote add origin git@github.com:<user>/Kumanpc-ru.git
# git branch -M main && git push -u origin main
```

Затем на GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
После пуша сайт появится по адресу `https://<user>.github.io/Kumanpc-ru/`.

Локальная проверка перед публикацией:

```bash
cd site && python3 -m http.server 8000
# открыть http://127.0.0.1:8000/
```

## Ответственность

Приложение не подключено к платёжным сервисам: списать средства и принять оплату оно не может.
Заказы не отправляются на сервер и хранятся только на устройстве.
